## Thesis (unchanged)

**Memory IS the intelligence. The model is fuel.** The brain persists
across devices, models, and channels. Intelligence lives in the *coupling
between memory, learning rules, and self-knowledge* — not in the fuel.
Adding modules doesn't add intelligence; the brain gets smarter when its
coupling tightens (better learning, more honest calibration, more reuse of
proven procedures).

This is the position Orion sidesteps — never claims — on machine
consciousness: we build *functional* metacognition, not phenomenal.

## What changed about the brain's behavior

Before this session, the agentic stack was closed but each piece learned in isolation. After:

1. **Self-repair learns calibration** — repeated restart failures on a device flip the governor from auto→ask on that device class. Recovery from real outcomes.
2. **The skill library learns curation** — chronic-hurt skills get retired by the Library-Drift ratchet; new births refuse twin-overlap above 0.7 Jaccard. The library is *provably non-regressing*.
3. **The will learns user receptivity** — chronic deferrals across kinds raise the meta-calibration signal; the will stops nagging without per-kind silos waiting to learn separately.
4. **The mesh learns together** — every host's earned calibration (per-shape) propagates as a bounded CRDT aggregate; remote evidence enters governor decisions at half weight.
5. **The brain measures itself** — composite published, jsonl trajectory written, single graphable number.

The brain went from *closed* to *unified-and-measurable*.

## The fresh-install test (today)

This snapshot is being written immediately before the founder runs the
production version of Orion as a fresh install on a clean LLM (Alien
machine, Ollama base). The test answers ONE question:

**Does the brain we built make the underlying LLM behave like Orion?**

Identity persistence, memory across sessions, calibrated metacognition,
hedging on uncertainty, source-attributed claims, no fabricated user
history — these are the contract. Pass = production-ready; fail = the
work is structural code that hasn't yet bridged to the live LLM
experience, and we know exactly what to wire next.

The test is the only honest measure that turns 13 commits into an
*entity*. Everything below the test is plumbing; everything above is
the engine that fueling LLMs become.
